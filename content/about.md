# このサイトについて

補助金ウォッチは、国・都道府県・市区町村が公募している補助金・助成金を、対象地域・目的・締切ごとに整理して毎日自動更新しているサイトです。

## データの出どころ

掲載している補助金の情報は、デジタル庁が運営する補助金申請システム「jGrants」の公開 API から取得しています。取得は毎朝 1 回自動で行い、新しく公開された補助金の追加と、締切や金額の変更の反映を行っています。

各ページの「公式の概要」は jGrants に掲載された内容をそのまま引用したもので、出典と取得日を明記しています。その他の解説文は当サイトが独自に書いたものです。

## 情報の扱いについて

- 掲載内容は取得時点のものです。金額・要件・締切は変更されることがあります。
- 申請にあたっては、必ず各ページからリンクしている公式ページと公募要領で最新の情報をご確認ください。
- 当サイトの情報をもとに行った判断や申請の結果について、当サイトは責任を負いかねます。
- 当サイトは申請の代行や相談は行っていません。

## 広告について

当サイトの運営費用をまかなうため、アフィリエイト広告を掲載することがあります。広告の掲載有無は補助金の並び順や掲載内容に影響しません。

## お問い合わせ

掲載内容の誤りや削除のご要望は、サイト運営者まで GitHub リポジトリの Issue からご連絡ください。
