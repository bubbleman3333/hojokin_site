# 記事の置き場

`<補助金コード>.md`（例: `S-00009860.md`）を置くと、その補助金のページの解説文として使われる。
無い補助金はデータから自動で組み立てた文章で埋まる。どの補助金に記事が無いかは
`python -m hojokin pending` で出る（締切が近い順）。元データは `data/subsidies/<id>.json` にある。

## 形式

```
---
title: 検索する人が打ちそうな言葉を入れた記事タイトル（40 字前後）
summary: 120 字前後の要約。検索結果の説明文になる
---
## 見出し
本文（Markdown）
```

## 書くときの決まり

- 元データ（`detail` や補助率・上限・締切）に書いてあることだけを書く。**無いことを足さない**。
- 上限額・補助率・受付期間・対象地域・業種は本文の上の表に自動で出るので、本文で繰り返し並べない。
  本文は「誰に向いているか」「使いみちの例」「注意点」「似た制度との違い」のような、表からは読めないことを書く。
- 見出しは `##` で 3〜5 個、全体で 600〜1,000 字。
- 「必ず採択される」「簡単にもらえる」のような断定はしない。
- 出典表示と公式ページへのリンクはテンプレートが出すので書かなくてよい。
